How it works

The app is built for a simple workflow: submit a recording, monitor its status, and review the generated transcript when processing finishes.

Upload and configure

Choose your recording, set language mode, and select the expected speaker count before creating the job.

Track processing

Each job clearly shows whether it is uploaded, processing, completed, or failed.

Review results

Open the job detail page to read the transcript and access uploaded or normalized audio files.

Use the history page

Browse previous jobs, filter by status, and return to any transcript from the jobs list.
